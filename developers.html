Orbit API

A REST API and webhooks for your Orbit company data - contacts, products, projects, invoices, purchase orders and payments. Read everything; create and update your master data; get notified in real time.

Base URL & authentication

All requests go to:

https://orbit.spacework.ai/api/v1

Create an API key in Orbit under Settings › Developers (API). Send it as a Bearer token on every request. A key belongs to one company and can only ever read or write that company's data.

Authorization: Bearer orbit_live_xxxxxxxxxxxxxxxxxxxxxxxx
Keep keys secret - treat them like a password. Use them from your server, never from browser code a visitor can read. Revoke a key any time in Settings; it stops working immediately.

Reading data

MethodPathReturns
GET/{resource}A page of records: { data:[...], count, limit, offset }
GET/{resource}/{id}One record: { data:{...} }

Readable resources: contacts, products, projects, invoices, purchase_orders, payments. Paginate with ?limit= (max 200) and ?offset=.

curl https://orbit.spacework.ai/api/v1/contacts?limit=20 \
  -H "Authorization: Bearer orbit_live_xxx"

{
  "data": [
    { "id": "3f2a...", "name": "Skyline Developers", "email": "ap@skyline.com",
      "is_customer": true, "is_vendor": false }
  ],
  "count": 1, "limit": 20, "offset": 0
}

Writing data

Create and update is enabled for master data: contacts, products, projects. The key needs the write scope. Financial documents (invoices, purchase orders, payments) are read-only for now, pending a security review.

MethodPathBody
POST/{resource}JSON object of fields → creates, returns { data:{...} } (201)
PATCH/{resource}/{id}JSON object of fields to change
curl -X POST https://orbit.spacework.ai/api/v1/contacts \
  -H "Authorization: Bearer orbit_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "name":"New Vendor Ltd", "email":"hello@newvendor.com", "is_vendor":true }'

Writable fields - contacts: name, email, phone, vat, is_company, is_customer, is_vendor, industry. products: name, default_code, type, list_price, cost_price, uom, family, is_active. projects: name, code, partner_id, contract_value, status, date_start, date_deadline. The company is set for you and cannot be overridden.

Webhooks

Add an endpoint under Settings › Developers (API) and pick the events you want. When one happens, Orbit POSTs JSON to your URL:

POST your-url
X-Orbit-Event: invoice.created
X-Orbit-Signature: sha256=<hex hmac>

{ "event":"invoice.created", "company_id":"...", "created_at":"...",
  "data": { "id":"...", "number":"INV/2026/0007", "amount_total":1200.00, "state":"posted" } }

Events: invoice.created, bill.created, purchase_order.created, purchase_order.confirmed, payment.recorded.

Verify the signature

Each endpoint has a signing secret (shown once when you create it). Compute HMAC-SHA256(raw_body, secret) and compare, in constant time, to the hex in X-Orbit-Signature (after sha256=). Reject the request if it does not match.

// Node
const crypto = require("crypto");
const sig = "sha256=" + crypto.createHmac("sha256", SECRET).update(rawBody).digest("hex");
if (!crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(req.headers["x-orbit-signature"]))) reject();

Errors

Errors return a JSON body { "error": "..." } with a standard status: 401 invalid/missing key, 403 read-only key or non-writable resource, 404 unknown resource or record, 400 bad request.
